Privacy Policy

Last updated: 24 November 2026

Sounded Crazy Poster ("the app") is a personal publishing tool run by the owner of the Sounded Crazy channel. Its only user is that owner.

What the app accesses

  • Sign-in tokens for the owner's own YouTube, Instagram, Facebook and TikTok accounts, granted by the owner through each platform's official login.
  • Basic account information each platform returns with that login (account ID and username), used only to post to the right account.
  • The owner's own video files and captions, which the app uploads.

What the app does not do

  • It does not collect, store or process data about viewers, followers or any other person.
  • It does not read messages, comments, contacts or analytics about other people.
  • It does not sell, share or transfer any data to third parties, and it shows no ads.

Storage

Tokens are stored only on the owner's own computer, in a private settings file that is never published. Video files are stored briefly on the owner's own cloud storage so that Instagram and Facebook can fetch them, and are deleted after posting.

Google user data

The app uses the YouTube Data API only to upload the owner's videos to the owner's channel. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be withdrawn at any time from each platform's connected-apps settings (Google account permissions, Instagram "Apps and websites", Facebook "Business integrations", TikTok "Manage app permissions"). Withdrawing it stops the app immediately; the owner then deletes the stored tokens.

Contact

Questions about this policy: open an issue at github.com/owenchlee/soundedcrazy/issues.
